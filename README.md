# Kaprekar Worlds

A systematic computational survey of Kaprekar's routine for 2–100 digit numbers in bases 2–100.

## Contents

- `kaprekar_simulation.ipynb` – Jupyter notebook with simulation code
- `/data` – CSV files containing simulation results

## Usage

Open the notebook in Google Colab or locally. Run all cells. The simulation will prompt for parameters and save outputs as CSV.

## Paper

A full research paper describing the findings (including new constants like `3032₅` and the 3‑digit even‑base formula) is in progress.
